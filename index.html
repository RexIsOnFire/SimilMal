SimilMal is an educational, static demonstration. Similarity is computed with a weighted multi-feature Jaccard/containment model over a curated offline corpus. It is not a substitute for a sandbox or professional malware analysis platform.

API settings

SimilMal can attempt a live lookup on MalwareBazaar (abuse.ch) for hashes not in the bundled corpus. This needs your own Auth-Key, stored only in this browser (localStorage) and never sent anywhere except MalwareBazaar. Browser access also depends on MalwareBazaar allowing cross-origin requests; if it doesn't, SimilMal falls back to the bundled corpus.
