SimilMal is an educational, static demonstration. Similarity is computed with a weighted multi-feature Jaccard/containment model over a curated offline corpus. It is not a substitute for a sandbox or professional malware analysis platform.

Live lookup settings

MalwareBazaar requires an API key on every request and sends no CORS headers, so a static site cannot call it directly from the browser. To enable live lookup, deploy the included proxy Worker (worker/malwarebazaar-proxy.js) — a free Cloudflare Worker that holds your MalwareBazaar key server-side and adds CORS — then paste its URL below. Your key stays in the Worker; it is never stored in this page or your browser. Setup steps are in the project README.
